# GCS Share

Simple, fast file sharing between devices.

**Website:** https://gcs-share.vercel.app

## Features

- Share files between paired devices
- QR code device pairing
- No accounts required
- Browser-based, no installation needed
- Secure cloud storage

## Tech Stack

- Node.js
- Express
- Neon PostgreSQL
- Filebase
- Vanilla HTML, CSS and JavaScript
- Vercel

npm install
npm run dev
